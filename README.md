\# Evently Frontend



Учебный проект по разработке интерфейса для управления событиями. 

В проекте реализована ролевая модель доступа и административная панель.



\## Автор

\*\*Денисов Михаил Юрьевич\*\*



\## Стек технологий

\* \*\*Vue.js 3\*\* (Composition API / Options API)

\* \*\*Vite\*\* (сборщик)

\* \*\*Vue Router\*\* (навигация)

\* \*\*PrimeVue\*\* (UI-компоненты)

\* \*\*Axios\*\* (работа с API)



\## Роли и тестовые аккаунты

В приложении реализовано 3 роли: \*\*Гость\*\*, \*\*Пользователь\*\* и \*\*Администратор\*\*.
